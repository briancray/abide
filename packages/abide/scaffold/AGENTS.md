# Working on this app

This is an abide app. Before writing code, read `node_modules/@abide/abide/ABIDE.md`: how an abide
app is laid out, checked and tested, and what this file is for. It ships with abide and updates
with it.

## This app

- `src/getGreeting.handler.ts` and its test are the pattern for a handler and the test that calls
  it; `src/index.test.ts` is the pattern for a page test that counts the work a click did.

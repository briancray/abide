---
"@abide/abide": minor
---

A database's tables are typed from its migrations and described by the file itself. `database` carries the tables its `CREATE TABLE` / `ALTER TABLE` / `DROP TABLE` strings leave, so `table(db, 'deals')` is typed with no generic and a misspelled name is a type error, and `Tables<typeof db>['deals']` names a row (47.48-47.50). A `table` writes by the table's own primary key, composite ones included, rather than `id` (47.30, 47.40); a column declared `BOOLEAN` reads as `true`/`false` and one declared `JSON` as its parsed value, through a table, its changes and `sql` (47.41, 47.42). An `IN` list of any length binds in one statement per power of two, and one past 1024 values as a single JSON value, so a call site no longer prepares a statement per length or fails past SQLite's variable limit (47.37). `logged` keeps wide columns out of the change log (47.43); a write inside a transaction refreshes on its commit (47.44); a reader is never handed a gap (47.31, 47.45). Migrations run with foreign keys checked once at the end, so a table rebuild no longer cascades (47.46), and `database` opens with `synchronous = NORMAL` and keeps the planner's statistics with `PRAGMA optimize` (47.5, 47.47). A table also has `peek` (a read nothing follows), `insert` (the key left to SQLite, the stored rows answered) and `like` in a match; a plain object in `sql` binds as JSON; a column given `undefined` is not written; and declaring a table opens no database until it is used (47.51-47.39). `.as<{ col: Narrower }>()` narrows a JSON column or a text union on the typed table (47.54); triggers a rolled-back transaction unmade are made again (47.55); and an update that changes nothing records no change (47.56). Behavior changes: a `table` with no `key` whose primary key is not `id` now upserts by that key, and `BOOLEAN`/`JSON` columns read decoded.

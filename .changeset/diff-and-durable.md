A followed value that is replaced — `set`, a refresh, a reload — reaches every page standing at the version before as the JSON Patch from the old value to the new one, a list its `key` tells apart changed row by row, rather than as the whole value (18.41). A `memo` takes a `store` (one per args, `store: ({ id }) => store.sqlite(db, \`feed:${id}\`)`), so an entry opens on what was kept without running its function, and keeps what it produces and what its owner writes (11.78). A `job` takes a `store` for its status in place of `lastRun`: a restart reads when the last run ended, sends a missed time once, keeps the last result, and reads no run as going (54.17, 54.42).

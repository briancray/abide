`announce(text, { politeness })` has a screen reader read a message out with nothing shown, from an `Announcer` rendered once in the root layout (`import Announcer, { announce } from '@abide/abide/Announcer.abide'`): a polite and an assertive live region, standing empty from the first paint, each message replacing the last and the same words said twice read twice. A `Chart` announces its readout as the keyboard moves its crosshair (RULEBOOK 50.36, 50.49-50.52, 52.71).

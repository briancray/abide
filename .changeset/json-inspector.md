`jsonInspector` searches and inspects a JSON value as parts an app spreads on markup of its own: a search field, and `tree`'s parts over a row per value told apart by its JSON Pointer, rendered flat. A search shows only the matches and the rows holding them, opened, marks each match in runs, and leaves `expanded` as it was (RULEBOOK 51.153-51.161). `tree` hands back `shown`, the nodes that show in order, so any tree can render as one flat list (51.152)

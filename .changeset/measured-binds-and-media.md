`bind:size={box}` writes an element's content-box `{ width, height }` and `bind:visible={seen}` whether it intersects the viewport — one way, from one `ResizeObserver` and one `IntersectionObserver` shared by every bound element, unobserved when the element leaves, and nothing written by the server (RULEBOOK 32.79-32.85). `bind:rect={placed}` writes the element's viewport rectangle as `getBoundingClientRect` reports it, re-read in one animation frame after a resize of the element, a scroll anywhere in the document, a window resize, or any other move of the element, which an `IntersectionObserver` fitted to its last rectangle reports — one scroll and one resize listener for every bound element, every read before any write, and nothing observed again while nothing moves (RULEBOOK 32.86-32.90). `media(query)` is a `Reactive<boolean>` following `matchMedia`, one value per query text, `false` on the server (RULEBOOK 23.30-23.32). While a page hydrates, `media` and `online` answer as the server did and are written the browser's answer once it has, so an `{#if}` they change is swapped as an update, with no 41.24 warning (RULEBOOK 41.32).

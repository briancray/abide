`onPairing(() => args)` from `@abide/abide/server` files the Claude Code arguments every pairing's command and install carry after `--`, asked in the asking request's scope — so a site can hand each person their own `--mcp-config` or `--allowedTools` through the built-in `/__abide/pairing` rather than a bridge handler of its own. Each argument is quoted where a shell would split it, the link carries none, and a request still names none (RULEBOOK 44.74, 44.76, 37.7).
